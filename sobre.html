SOBRE O PROJETO

Conheça o Latinidade

Um projeto desenvolvido para apresentar a diversidade cultural, turística e gastronômica da América do Sul.

NOSSO PROJETO

Uma viagem pela América do Sul

O Latinidade é um projeto de desenvolvimento web criado com o objetivo de apresentar diferentes aspectos da América do Sul.

O site reúne informações sobre os países, destinos turísticos, gastronomia e cultura do continente, destacando a diversidade presente em cada região.

A proposta é proporcionar uma experiência simples e agradável para quem deseja conhecer um pouco mais sobre a história, os costumes e as paisagens dos países sul-americanos.

LATINIDADE

Diversidade que conecta

A América do Sul reúne diferentes povos, culturas, idiomas, tradições e paisagens. Essa diversidade é uma das principais características do nosso continente.

OBJETIVO

O que queremos apresentar

O Latinidade busca reunir informações de forma organizada e acessível, valorizando diferentes aspectos dos países da América do Sul.

🌎

Países

Apresentar os países que fazem parte da América do Sul e algumas de suas principais características.

🏔️

Turismo

Mostrar destinos turísticos e paisagens que fazem parte da diversidade natural do continente.

🎭

Cultura

Valorizar músicas, festas, tradições, costumes e outras manifestações culturais da América do Sul.

DESENVOLVIMENTO

Tecnologias utilizadas

Para desenvolver o projeto foram utilizadas tecnologias de desenvolvimento web e ferramentas de estilização.

HTML5 Utilizado para estruturar as páginas e organizar o conteúdo do site.
css3 Utilizado para personalizar o visual, cores, fontes, espaçamentos e outros elementos do projeto.
Bootstrap 5 Framework CSS utilizado para criar layouts responsivos e facilitar a organização das páginas.
JavaScript Utilizado para adicionar funcionalidades e interações ao site.
